## 읽기 기능

- 책 표지 · 부 표제지 · 장 번호가 있는 종이 느낌의 레이아웃 (모바일 반응형)
- 좌우 스와이프 / ← → 키로 책장 넘기기, 상단 읽기 진행 막대
- 글자 크기 · 명조/고딕 · 종이/흰색/밤 테마 설정
- 이어 읽기, 읽은 장 ✓ 표시, 부별 진도율 (브라우저에만 저장)
- 제목 + 본문 전문 검색 (`/` 키)
- 매일 바뀌는 "오늘의 경제 상식"
- 각 장마다 도입 이야기 · 핵심 개념 · 숫자 예시 · 흔한 오해 · 뉴스 읽기 · 1분 퀴즈

## 구조

```
index.html          뷰어 (빌드 과정 없음)
assets/style.css    디자인
assets/app.js       라우팅 · 렌더링 · 검색 · 설정
book.json           목차 (부/장 제목과 id)
chapters/1-01.md    본문 — 장 하나당 마크다운 파일 하나
WRITING_GUIDE.md    집필 원칙과 장 템플릿
```

## 글 추가·수정하기

1. `chapters/{id}.md` 파일을 고치거나 새로 만듭니다. 형식은 [WRITING_GUIDE.md](WRITING_GUIDE.md)를 따릅니다.
2. 새 장이면 `book.json`의 해당 부 `chapters` 배열에 `{ "id": "...", "title": "..." }`를 추가합니다.
3. 커밋·푸시하면 GitHub Pages에 바로 반영됩니다.

마크다운에서 쓸 수 있는 요소: 표, `> [!TIP]` / `> [!NOTE]` / `> [!WARNING]` / `> [!IMPORTANT]` 강조 상자, `<details><summary>정답 보기</summary>…</details>` 퀴즈, 다른 장 링크 `[기준금리](#/1-24)`.

## 로컬에서 보기

`fetch`로 파일을 읽기 때문에 파일을 더블클릭하면 열리지 않습니다. 간단한 웹서버로 여세요.

```bash
python -m http.server 8000
# http://localhost:8000
```

## 배포 (GitHub Pages)

저장소 **Settings → Pages → Build and deployment**에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 지정하면 끝입니다. (`.nojekyll` 파일이 있어 마크다운이 원본 그대로 제공됩니다.)
